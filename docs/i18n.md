# Add a language in under five minutes

1. Copy `src/i18n/en.json` to `src/i18n/<code>.json` and translate the values, keeping keys and placeholders intact.
2. Copy `src/i18n/exercises.en.json` to `src/i18n/exercises.<code>.json` and translate every exercise `name` and `cue`.
3. In `src/i18n/config.ts`, add the code to `supportedLanguages`, add a lazy `languageLoaders` import for the message JSON, and add an `exerciseLoaders` import for the exercise strings.
4. Add a translated `settings.language<Code>` label in each shipped messages file.

`setLanguage()` lazy-loads registered dictionaries. The message helper falls back to English for missing keys and uses `Intl.PluralRules` when a key resolves to `{ "one": "…", "other": "…" }`. Interpolation uses `{{name}}` placeholders. Dates and numbers use `Intl` formatters; stored weights and OpenAI loads remain kg, with display conversion in the UI.

Exercise records in `src/data/exercises.json` contain only language-neutral IDs, muscles, movement patterns, levels, types, equipment, and progression links. User-selected language is sent to the model so the free-text coach and cue fields use that language.
